Upload a match pack

Video (720p, ~1–2 GB) plus match facts — lineups, formation, goals, cards, substitutions, optional corners / free kicks / offsides. Facts are treated as truth; the sheet fills those fields now. Possession, xG, PPDA and pass accuracy come in later phases.

World Cup open-data on Match stays the gold-standard example. This pack path is how you collect your games without a paid feed.

2. Match facts

JSON with home/away lineups + formation, timed events, optional set-piece totals. Download JSON

Drop a UTF-8 .json facts file (e.g. Napoli–Pisa). A bad file shows an error and keeps any facts already saved — it will not wipe the pack.

3. Formation PDFs & video

Formation PDFs are optional (stored + text-extracted). Video: MP4/MKV/MOV up to 4 GB, chunked 8 MB uploads — aim for 720p / 1–2 GB.

4. Compute fact-sourced sheet

Phase 1 fills goals, cards, substitutions, lineups/formations, and any set-piece totals you put in the JSON. Possession, xG, shots, passes, PPDA stay as — until later video phases — that is expected, not a bug.

5. Analyze video (Phase 2–8)

Phase 2–7: film through passes/tackles. Phase 8: progressive passes, aerials, interceptions, clearances. Still approximate — not Opta/StatsBomb. xG/PPDA stay pending.

Order: Analyze → Correct film → 3…7 → defence/progressive (8). Phase 3/4 can take a while on CPU — keep this tab open.
